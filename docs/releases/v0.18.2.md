## Conduit v0.18.2

This release upgrades the service behind your account, sync and cloud backups, and makes it easier to create entries from the side bar.

### Good to know
- You need to sign in once after updating. Use the same email and password as before. Your vaults, backups, teams and plan are all still there.
- If you use an authenticator app, the first sign-in sends a code to your email instead. Then you scan a new QR code, and your authenticator works as before.
- Older versions of Conduit show "Update required" and stop syncing until you update.

### New
- Right-click the empty part of the side bar to create any type of entry or a folder, even in an empty vault.
- Folder menus have a New Entry list with every type, and entry menus have "New in This Folder".
- The "+" button at the top of the side bar lists every entry type, Choose Type... and New Folder.
- Settings > Sessions > Terminal has a Font Family option. Type any installed font or browse for one.

### Improved
- Account, sync and cloud backup now run on an upgraded service.
- Creating an entry from a menu skips the type picker and fills in the default port.
- Nerd Font icons now fit their cells in every terminal.

### Fixed
- Changing an entry's type no longer keeps the old port or SSH key setting.
