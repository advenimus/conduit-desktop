## Conduit v0.19.0-beta.1

This is a beta. It lets you reach Windows computers that sit behind a Remote Desktop Gateway, and it starts the beta channel so you can try new features early.

### New
- **Remote Desktop Gateway**: an RDP entry can now connect through a gateway. Open the entry and pick the Gateway tab.
- **Gateway per entry or by default**: choose Use default gateway, No gateway or Custom gateway. Set the default in Settings > Sessions > RDP.
- **Gateway login**: use the same login as the computer, or pick a saved credential for the gateway.
- **Skip the gateway for local addresses**: a gateway can connect straight to computers on your local network.
- **Clear gateway errors**: a wrong gateway password, a gateway that can't be reached, or a computer the gateway won't allow each get their own message.
- **Beta updates**: Settings > General > Updates has a "Get beta updates" switch and a Check for updates button.

### Good to know
- Beta builds use your normal account, plans and vaults. Nothing moves to a test server.
- You got this beta, so beta updates are on. Turn them off in Settings > General > Updates.
- Turning beta updates off never moves you to an older version. You'll move to the next regular release when it comes out.
- A small Beta pill shows in the title bar while you're on a beta.
- Gateway settings are not on iPhone and iPad yet.
