## Conduit v0.18.4-beta.1

This is a beta. It lets you reach Windows computers that sit behind a Remote Desktop Gateway.

### New
- **Remote Desktop Gateway**: RDP entries can now connect through a gateway.
- **Gateways you set up once**: add one with New Entry > RD Gateway, then pick it on any RDP entry's Gateway tab. You can also make one right from that tab.
- **Gateway login**: type in a login for the gateway, use a saved credential, or use each RDP entry's own login.
- **Skip the gateway for local addresses**: a gateway can connect straight to computers on your local network.
- **Clear gateway errors**: a wrong gateway password, a gateway that can't be reached, or a computer the gateway won't allow each get their own message.

### Good to know
- Beta builds use your normal account, plans and vaults. Nothing moves to a test server.
- You got this beta, so beta updates are on. Turn them off in Settings > General > Updates.
- Turning beta updates off never moves you to an older version. You'll move to the next regular release when it comes out.
- A small Beta pill shows in the title bar while you're on a beta.
- Gateways are not on iPhone and iPad yet. There a gateway shows as a regular credential, and RDP entries connect without it.
