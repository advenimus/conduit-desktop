## Conduit v0.18.4-beta.3

This is a beta. It fixes the problems found while testing beta.2. Try double-clicking entries, signing out of a remote desktop, and using a narrow side bar.

### New: certificate checks and clearer TLS errors
- **Trust a certificate on first connect**: when a computer or gateway shows a certificate this device does not trust, or one made out to another name, Conduit asks first. Pick Trust once, Always trust or Cancel. The question shows who the certificate is for, who issued it, its dates and its SHA-256 fingerprint.
- **Changed certificate warning**: if a certificate you chose to always trust changes, Conduit warns you and asks again.
- **Company certificates just work**: certificates your Mac or PC already trusts, for example from a company CA in Keychain, connect without a question.
- **Clearer secure-connection errors**: when the secure (TLS) connection fails, the error now says why, for example an old TLS version, a server missing a security update, or a port where nothing answers. The technical reason shows under it.
- **Allow old TLS**: a new switch for old servers that only offer TLS 1.0 or 1.1. Find it on a gateway's Server tab under Advanced, and on an RDP entry's Security tab.
- **Skip certificate verification** is now a setting on an RDP entry's Security tab.

### Good to know: certificates
- Always trust is remembered on this device only. It does not sync to your other devices.
- AI agents that open RDP connections get the same check. The question shows in the app, and if no one answers within a minute the agent gets an error that says how to fix it.
- Allow old TLS is less secure. Turn it on only for a server that fails without it.
